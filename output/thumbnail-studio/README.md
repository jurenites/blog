# Jurenites — Signal / Layers

Open **jurenites-thumbnail-studio.blend** in Blender. Choose MONITOR, LAPTOP or
PHONE in the Scene selector. The file includes a **START HERE** text block.

- `*-8s.mp4`: three eight-second motion previews, 768×480, 24fps.
- `renders/*-still.png`: three 1600×1000 thumbnail renders.
- `signal-stripes.svg`: transparent stripe motif.
- `signal-background.svg`: motif on the project background color.
- `verification.json`: checked video metadata and loop closure.

The complete editing guide and photographic matching advice are in
[docs/thumbnail-studio.md](../../docs/thumbnail-studio.md).

Laptop: MacBook Pro M3 by jackbaeten, CC BY 4.0; see source-assets/macbook/CREDITS.txt.
Monitor and phone: original simplified Apple-inspired geometry. Not official Apple CAD. Packed screenshot: existing Oksenate project asset.
